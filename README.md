# Money Well Spent

A simple, responsive static website for Money Well Spent.

## Files
- `index.html` — homepage
- `styles.css` — shared styling
- `about.html` — about page
- `disclosure.html` — affiliate disclosure
- `articles/accutane-products-for-dryness.html` — skincare guide

## Adding an article
1. Create a new HTML file in `articles/`.
2. Link `../styles.css` in the page's head.
3. Reuse the header/footer from an existing article and update the content.
4. Add a card or link on `index.html` so visitors can find it.
5. Commit the changes to the main branch. Once the repository is connected to Vercel, pushes to the production branch will trigger deployments.

Affiliate links should be clearly disclosed. Make it clear which products were personally tried and which were researched. Health-related content should not replace professional advice.
